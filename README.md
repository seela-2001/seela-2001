## 🔥 Featured Projects

### 🌡️ ThermoRoute — Intelligent Route Risk Analysis

A full-stack application that analyzes routes based on environmental and temperature-related risks.

**Built with:** Django · PostgreSQL · React · Docker · Kubernetes · AWS EKS · Terraform · Helm · Argo CD · AI

- 🗺️ Route analysis using OSRM
- 🤖 AI-powered route explanations
- 🌡️ Environmental risk assessment
- 🐳 Dockerized backend and frontend
- ☸️ Deployed on AWS EKS
- 🚀 Automated deployment with Argo CD
- 🏗️ Infrastructure provisioned with Terraform

### ☁️ CloudBite — Production-Style DevOps Deployment

A containerized food-delivery application used to practice a complete DevOps workflow.

**Built with:** React · Node.js · MongoDB · Docker · Kubernetes · Helm · Argo CD · AWS

- 🐳 Multi-container Docker architecture
- ☸️ Kubernetes deployment
- 📦 Helm-based application management
- 🚀 GitOps deployment with Argo CD
- 📈 Monitoring and observability
- 🔐 Kubernetes secrets and security practices

### 🔐 Kubernetes Security Lab

A hands-on Kubernetes security project focused on applying real-world cluster security concepts.

**Topics covered:** RBAC · Certificates · Network Policies · Security Contexts · Service Accounts · Storage · Private Registry

- 🔑 Kubernetes authentication and authorization
- 👤 User certificates and kubeconfig contexts
- 🛡️ Role-Based Access Control
- 🌐 NetworkPolicy-based service isolation
- 🔒 Security contexts
- 💾 Persistent storage
